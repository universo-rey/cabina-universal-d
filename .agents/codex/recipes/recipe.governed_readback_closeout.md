# recipe.governed_readback_closeout

## Purpose

Close local D-drive agent-layer work with evidence, validator status and explicit boundaries.

## Steps

1. List touched files.
2. List surfaces not touched.
3. Record validator command and result.
4. Record secret-scan result.
5. Record remaining risk.
6. Declare next lanes, not a single vague next step.

## Output

`READBACK_<FRONT>_<YYYYMMDD>.md`

## Stop Condition

Stop if validation was not run or if external/live surfaces were touched without order.
