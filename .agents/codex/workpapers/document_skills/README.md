# Document Skills Workpapers

This folder stores sanitized workpapers for document-skill lanes.

Allowed here:

- document type classification notes
- template references
- render or preview QA summaries
- redline plans without document body dumps
- sanitized output manifests

Blocked here:

- secrets
- broad regulated document bodies
- live Microsoft, SharePoint, Outlook, Teams or Google Drive exports
- production artifacts without separate governed order
