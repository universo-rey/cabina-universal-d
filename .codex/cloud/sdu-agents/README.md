# SDU Agents Codex Cloud Pack

Repo-scoped task templates for the SDU chain. Consume AGENTS.md and the
proportional execution policy: READ is direct, bounded LOW patches need no
separate approval, and positive HIGH effects retain exact explicit authority.

profile.yml describes available actions; each task limits its own scope.
Validator repair permits codex_cloud_apply for the authorized branch patch.
Review-only tasks remain read-only. This template does not create a connected
Cloud environment or persistent remote agent.

setup.sh and maintenance.sh are local templates. Task changes require relevant
validator results and a reviewable diff, not a global audit or previous receipt.
Missing capabilities or targets stop only the affected operation. Keep secrets
out of the repository and logs.
