# SDU Agents Codex Cloud DEV Pack

This pack prepares repo-scoped Codex Cloud delegation templates for the SDU
chain. It does not execute remote writes.

## Files

- `profile.yml`: governed profile.
- `setup.sh`: local environment precheck template.
- `maintenance.sh`: validation maintenance template.
- `tasks/`: task prompts for read-only or review-first cloud work.

## Boundary

- No apply.
- No production.
- No Microsoft live.
- No OpenAI live.
- No material sensitive storage.
- No remote persistent agent.
