C_ROOT_REFERENCE_PLANE_ANCHOR

Esta carpeta es el ancla repo-scoped de referencias tecnicas para
`universo-rey/cabina-universal-d` cuando la cabina opera desde:

```text
C:/Users/enzo1/Documents/GitHub/cabina-universal-d
```

No es canon institucional por si misma. No habilita ejecucion live de vendors,
OpenAI API, Microsoft 365, Power Platform, produccion, permisos, secretos ni
costos externos.

La superficie historica:

```text
D:/80_REFERENCIAS_TECNICAS
```

queda como legacy/read-only/gobernada hasta una decision explicita de metadata
retention. No se copia, mueve ni absorbe desde este carril.

Uso permitido:

- clasificar referencias tecnicas locales;
- separar referencia tecnica de canon rector;
- dejar notas saneadas de frontera, fuente, frescura y licencia;
- validar `tool.reference_classifier` contra la raiz Git efectiva en C.

Uso bloqueado:

- tratar referencias tecnicas como autoridad rectora;
- ejecutar vendor live sin gate;
- persistir secretos;
- escribir en tenants, produccion o superficies externas;
- modificar `D:/.git`, `core.worktree`, remotos, ramas o clones.
